# llm-roofline-bound

LLM 推理容量的**可证明理论下界**，加上**明确标注的估算值**。

给定模型、加速卡、部署方式（TP/PP/EP、精度）和负载，算出**无法被超越**的极限：最小 TTFT 和 TPOT、最大吞吐和并发、最少需要几张卡。

- 能从模型 config 和硬件规格精确推导的值，都会算出来。
- 推导不出来的，由你提供，并在结果里明确标注。

> **状态：pre-alpha（P1）。** 显存部分已完成：参数量、每卡权重、KV cache，以及在显存约束下最多能放下多少。延迟和吞吐的下界是下一步。详见 [docs/PLAN.md](docs/PLAN.md)。

## 每个数字都标明可信程度

| 级别 | 含义 | 显示方式 |
|---|---|---|
| `EXACT` | 只对 config 和规格做算术，不含假设 | `753,330,000 param [EXACT]` |
| `EXPECTED` | 在明确的统计假设下取精确期望，附带保证范围 | `223 expert [EXPECTED 64..256]` |
| `BOUND` | 可证明成立的不等式 | `≥ 1.23 s [BOUND]` |
| `ASSUMED` | 由你提供的建模输入 | `[ASSUMED]` |
| `ESTIMATE` | 下界乘以你提供的效率系数 | `≈ 18 ms [ESTIMATE]` |

这些规则由代码强制执行，不靠使用者自觉：

- 运算结果的可信程度不会高于最弱的那个输入。
- 界的方向如果无法确定，计算会直接报错。
- 需要你提供的值，永远不会被悄悄填上默认值。
